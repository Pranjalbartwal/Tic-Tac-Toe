
Tic Tac Toe Game – Using Python Programming

A simple and fun Tic Tac Toe game developed using Python. In this game, you play against the computer, where you take turns placing your marks on a 3×3 board. The first player to get three marks in a row, column, or diagonal wins the game.

 About the Project

This project is a beginner-friendly Python game created to practice basic programming concepts and improve logical thinking.

The game allows a user to play against the computer. After each match, you can choose to play again without restarting the program.

 Features

- Play against the computer.
- Interactive 3×3 game board.
- Automatic winner detection.
- Detects draw situations.
- Checks invalid moves.
- Option to play multiple rounds.
- Simple and easy-to-use interface.

How to Run the Project

Follow these steps to run the game on your computer.

1. Clone the repository**

```bash
git clone https://github.com/Pranjalbartwal/Tic-Tac-Toe.git
```

2. Open the project folder**

```bash
cd Tic-Tac-Toe
```

3. Run the Python file**

```bash
python "tic tac toe.py"
```

Make sure Python 3 is installed on your computer.

 How to Play

1. Run the Python program.
2. The game displays a 3×3 Tic Tac Toe board.
3. You play using `X`, and the computer plays using `O`.
4. Enter your desired position to make a move.
5. The computer automatically makes its move.
6. The game announces the winner or a draw.
7. After the match, choose whether you want to play again.
